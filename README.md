# Smart Discord Auto-Reply Bot

Умный автоответчик для одного сервера: бот анализирует сообщения, ищет вопросы по заданным паттернам и отвечает подготовленным текстом. Управление ответами и списком администраторов полностью внутри бота.

## Быстрый старт

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env`:
   ```bash
   DISCORD_TOKEN=ваш_токен
   OWNER_ID=ваш_id_в_discord
   ADMIN_IDS=1234567890,9876543210
   GUILD_ID=опционально_ид_сервера
   DEFAULT_LANG=ru
   ```
3. Запустите:
   ```bash
   npm start
   ```

## Основные команды

> Команды работают в чате и ЛС. Префикс `#`.

### Роли
- **Овнер** — ID из `OWNER_ID`, может добавлять/удалять админов.
- **Админы** — могут управлять ответами и языком.

### Управление заметками (ответами)
- `#addnote <tag> | <lang> | <pattern1; pattern2> | <answer>`
- `#updatenote <tag> | <lang> | <pattern1; pattern2> | <answer>`
- `#delnote <tag> [lang]`
- `#notes` — список тегов
- `#<tag>` — показать ответ по тегу (например, `#usebot`)

### Управление админами (только овнер)
- `#addadmin <userId>`
- `#deladmin <userId>`
- `#listadmins`

### Языки
- `#setlang <lang>` — установить язык для системных сообщений и ответов по умолчанию
- `#getlang` — показать текущий язык
- `#langs` — список доступных языков

## Как добавить ответы на разных языках

Пример для русского и английского:
```
#addnote usebot | ru | как пользоваться ботом; как бот работает; где взять бота | Чтобы пользоваться ботом, добавьте его на сервер и используйте команды.
#addnote usebot | en | how to use the bot; how does the bot work | To use the bot, invite it to your server and check #notes.
```

Если язык не указан, используется текущий язык по умолчанию.

## Как работает умный ответ
- Бот проверяет, похож ли текст на вопрос (вопросительный знак или ключевые слова языка).
- Ищет совпадения по паттернам, включая небольшие опечатки.
- При нескольких совпадениях объединяет ответы в компактный текст.
